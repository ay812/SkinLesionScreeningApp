# SkinLesionScreeningApp

AI-based Android app for skin lesion screening using TensorFlow Lite (on-device inference).

## Features
- Image scanning (ScannerActivity)
- Chatbot (ChatbotActivity)

## Prerequisites
- Android Studio
- Android device or emulator (API level as in build.gradle.kts)

## How to run
1. Clone: git clone https://github.com/ay812/SkinLesionScreeningApp.git
2. Open the project in Android Studio
3. Wait for Gradle sync
4. Run the app on a device/emulator
